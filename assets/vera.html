difference images

These are drawn by subtracting one canvas rasterization from the other, not by blending two DOM layers. A CSS mix-blend-mode: difference stack leaves a visible outline even when both layers use the identical font, so it cannot distinguish a real difference from a compositing artifact.

hinting: what dropping it cost

The shipped faces are built with --no-hinting, which took the pair from 26,052 bytes of WOFF2 to 9,872. Vera is from 2003 and carries a hand-written instruction set that outweighs its own outlines. Both rows below are the same subset at the same 2048 units per em; the only difference is whether those instructions survived.

what font-synthesis is set to, and why

vera.css sets font-synthesis: style. The shear is allowed because it is a convincing fake; the weight smear is refused because, as measured above, it is not. Refusing weight also stops a request for 900 from matching the real 700 face and then being emboldened again on top of it.
